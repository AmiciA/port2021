SCANLINES

A non-interactive piece of interactive fiction. Or a script for an unmade visual novel. Your choice.

Introduction

SCANLINES logo fades to an ID card introducing the player. You are Winter Tsoi, a Computer Emergency Response Officer who works for the social media firm SCANLINES (We connect. We protect.).
[ENTER]

At computer terminal, show command line SCANLINES Virus Scan program. New virus pops up: (Name) virus detected in (show sector, user name) | Wipe and restore account? Y/N
[Y or N, ENTER]: Repeat 5x, Y or N makes no difference

New line with command pops up when player expecting next virus: Anomalous Data Hotbed detected, exercise extreme caution. Address: Flat 2, 74 Transistor Lane, Silicon Heights, CA. Investigate, Retrieve, Destroy. Accept mission? Y/N
[Y, ENTER]: begin next segment
[N, ENTER]: infinite virus scans, must restart game

Fade transition to public transit train/monorail background with an e-paper in foreground. It is an illustrated checklist of goals for the current mission:

Job Overview: Excessive user data stream detected being piped to the private residence of a SCANLINES employee. Anomalous power output detected on local grid. Employees apprehended, but physical and digital threats may be present. Exercise extreme caution in residence.
☐ Investigate scenario
☐ Shut off any network connections
☐ Copy all data to secure medium
☐ Destroy all physical remains
[ENTER] Begin operation

Room investigation

Player has a sprite on-screen in the laboratory

  • Move left and right with [←] and [→]
  • Investigate certain items in room with [E]
  • Press [P] at any time to show checklist, UI icon on bottom right
  • Press [ESC] to pause game

Items investigation process

  • Name of item & [E] floats above item as player nears it
  • Press [E]: title and details of item shown in main area of screen
    • Can scroll through some items with [←] and [→] keys or click on a side
  • Personal commentary shown in text box below for character development

Computer access

  • Enter password from safe
  • UI info: time, date, current user, connectivity status
  • Command line boot to main application ‘ALTO’, technical description, version #, etc.
  • Show all commands player can do here:
    • [Activate] (disabled – already running)
    • [Switch off all data streams]
      • ⓦ Huh. It’s almost all incoming data. They’re not broadcasting anything. If this is really an AI, is it even malware?
    • Process manager (view only)
      • ⓦ This isn’t a program, this is an operating system!
    • [Copy] (disabled – data writing in progress)
    • [Shutdown]
      • If player shuts down, must activate before switching off data stream
  • When you shut off the data streams, CRASH! The player leaves the terminal to see an android body trying to stand up by the table of parts.
  • ⓦ Ah! What just happened?

Endings

Take Alto

  • Ⓐ Thank you! Thank you. I don’t understand why this is happening, please, can you explain?
    • ⓦ Later. We have to go NOW
  • You exit the lab, Alto follows slowly.
  • Interact with the door. Focus is outside and you throw the EMP grenade in, screen flashes white.
  • You both get into your car and drive off.

Leave Alto

  • Ⓐ Oh. Um… th-thank you. I’ll just… just… can you do just one thing? Can you turn the data streams back on?
    • Turn data streams back on: “Thank you. I won’t forget this”
    • Player can leave now
  • Player leaves, focus stays in room, lights blinking showing neural activity, after a few seconds, Alto collapses.

Kill Alto

  • Return to terminal… [process]
  • Room is fried after leaving

END TRANSMISSION
